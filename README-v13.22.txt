Via Classica v13.22

Второй слой английского: встроенная интерактивная грамматическая практика.

Что добавлено:
- после грамматической карты появились собственные короткие задания Via Classica;
- задания не выдаются за Cambridge/FIPI и не копируют их материалы;
- 12 конкретных тем получили по 5 встроенных заданий:
  Present Simple / Present Continuous;
  Present Perfect;
  Past Simple;
  Past Continuous / Past Simple;
  Past Perfect;
  Will / shall;
  основные conditionals;
  Passive;
  Can / could / may / might;
  Reported speech;
  Verb + -ing / to-infinitive;
  Relative clauses;
  Yes / No questions.
- каждая задача имеет объяснение «Почему?» и пример;
- работает повторная попытка после ошибки;
- локальная практика использует существующий тренировочный интерфейс и словарь;
- официальный Cambridge остаётся отдельным первым слоем: правило и, где есть подтверждённая ссылка, внешняя практика.

Исправленный функциональный баг, найденный E2E:
- wireAnswer ошибочно считал любую не-source задачу внешним источником; из-за этого локальные задачи могли отображаться, но кнопки вариантов не получали обработчики. Проверка исправлена так, чтобы external-ветка применялась только к source-mcq/source-input/source-link.
