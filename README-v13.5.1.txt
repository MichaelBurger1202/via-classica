Via Classica v13.5.1 — bugfix release

Исправлено после повторной независимой проверки v13.5:
1. Исправлена проверка дат в импорте расписания: YYYY-MM-DD теперь валидируется корректным RegExp; дополнительно проверяется реальная календарная дата.
2. Исправлено удаление слов из словаря после поиска/фильтра: обработчик теперь работает и для .dict-delete-filtered.
3. Усилена защита localStorage в planner.js и app.js: повреждённые данные сохраняются в *_corrupt_backup, после чего модуль стартует с безопасным состоянием вместо падения.
4. Убрано ложное автоматическое присваивание B2 после первой английской сессии. CEFR остаётся неопределённым, пока профиль не накопит достаточно истории; интерфейс показывает «Профиль формируется».
5. Версии ассетов и Service Worker переведены на 13.5.1.

Ключи localStorage не менялись, чтобы сохранить данные пользователя при замене файлов сайта.
