Via Classica v13.8 — source bank expansion

Bank policy: no generated test questions. Writing and Speaking are excluded. Listening is represented only by real source tests, not synthetic audio.

Current bank: 1028 unique source-task records.
- 108 Cambridge English source questions from v13.7
- 920 question-level records from IELTS-up public Reading/Listening practice tests (Academic Reading tests 1–11; General Reading tests 1–2; Listening tests 5–14)

Each record points to the exact source section and question number. The site does not copy the source question text; the learner opens the original source and answers there, then enters/selects the answer in Via Classica.

Important: this release does NOT claim 5000 verified source questions. Reaching 5000 honestly requires ingestion of the larger FIPI open bank and additional IELTS/official source sets; those cannot be safely invented or represented as verified source tasks.
