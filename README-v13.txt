Via Classica v13 — cumulative release

v13 объединяет в одном полном архиве все изменения v10, v11 и v12.

Включено:
— v10: импорт и экспорт расписания, загрузка расписания из JSON/URL, сохранение пользовательских задач при обновлении плана;
— v11: личный словарь английского, кликабельные слова и фразы в заданиях, автоматическое добавление при первом нажатии, контекст и быстрый перевод;
— v12: исправление кликов по словам внутри вариантов ответа, клавиатурная навигация, фильтры и поиск словаря, ручное добавление и удаление, сохранение словаря на устройстве;
— PWA и service worker;
— актуальные файлы интерфейса Via Classica.

Важно: v13 — полный архив сайта, а не набор отдельных файлов-патчей. Для обновления замените файлы сайта содержимым этого архива целиком.

Пользовательские данные localStorage не удаляются самим обновлением файлов. Перед крупным обновлением рекомендуется сделать резервную копию данных браузера.

Файл расписания текущего учебного плана via-classica-schedule-current.json импортируется отдельно через интерфейс «Обновление расписания».
