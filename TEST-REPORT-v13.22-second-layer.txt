3. Real bug found and fixed during browser testing
Before the fix, local grammar tasks rendered but their option handlers were absent. Cause: isExternalSourceTask() returned true for every non-source task because it only checked !sourceReady(). The external branch then returned before wiring MCQ/input handlers.
Fix: external detection is now limited to source-mcq/source-input/source-link records that are not sourceReady().
After the fix, the browser test confirmed .english-option receives a click handler, selected state appears, and englishCheck becomes enabled.

4. Content policy / source integrity
The 60 tasks are original Via Classica practice. They are not presented as Cambridge questions and do not copy Cambridge question text. Cambridge remains the source for the first-layer rule/practice links.

5. Scope
The second layer currently covers 13 high-priority concrete grammar topics. The remaining 22 topics in the 34-topic grammar map still use the first-layer official material until dedicated original practice is added.
