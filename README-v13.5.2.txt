Via Classica v13.5.3

Исправления:
- удаление слов в словаре работает через делегирование и после фильтрации;
- кнопка «+ Добавить задачу» прокручивает к форме и ставит фокус в поле;
- дата «сегодня» рассчитывается по локальному календарю браузера, без UTC-сдвига;
- защищена запись состояния планировщика в localStorage;
- добавлена миграция старого автоматически записанного B2 из v13.5;
- версии ассетов и Service Worker обновлены до 13.5.3.

Часовой пояс не зашит в сайт: используется локальная дата устройства. Для Санкт-Петербурга это MSK / Europe/Moscow (UTC+3), без сезонного перевода часов.
