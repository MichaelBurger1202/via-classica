Via Classica v13.5.4 — многоступенчатый audit patch

Исправления после повторного аудита v13.5.2:
- строгая нормализация корневого localStorage для app/planner/English;
- защита задач, ссылок, словаря и истории от повреждённых типов данных;
- защита архива ссылок от небезопасных URL;
- валидация дат периода заморозки;
- ограничение ручной и импортируемой задачи по длительности;
- сохранение текущего AI-задания при перезагрузке страницы;
- нормализация пунктуации в проверке английских ответов;
- исправление разбора слов рядом с HTML-символами вроде “&”;
- контекстные ссылки на авторитетные ресурсы в английских заданиях;
- «Как лучше?» для корректных, но отличающихся от эталонного формулировок свободного ответа;
- корректное отображение CEFR-описания для разных уровней;
- версия PWA/cache 13.5.4.

Проверка релиза:
- node --check для всех JS;
- независимый статический аудит HTML/JS/asset versions;
- сценарные проверки дат и JSON расписания;
- unit-проверка wordHtml и нормализации;
- ZIP integrity.

Примечание: полноценный browser E2E в этой среде недоступен — Chromium headless не возвращает DOM и зависает на запуске. Это не выдается за пройденный E2E.
