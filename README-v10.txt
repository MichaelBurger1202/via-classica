Via Classica v10

Обновление расписания без изменения сайта:
1. Получи от ChatGPT файл via-classica-schedule.json после согласования расписания.
2. Открой Via Classica → Главная → «Обновление расписания» → «Загрузить файл».
3. Сайт заменит только автоматически созданные (plan) задачи. Ручные задачи, отметки и ссылки сохраняются.
4. Для ссылки используй прямую ссылку на JSON (например, Raw-ссылка GitHub). Браузер должен разрешать CORS.

Формат: via-classica-schedule-v1.
Пример файла: via-classica-schedule-example.json.
