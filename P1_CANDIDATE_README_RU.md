# Via Classica v14.7-p1 — кандидат исправлений F1/F3/F4

**Не является опубликованной или принятой версией. Не заменяет v14.6 без отдельной приёмки.**

Содержимое папки — автономные исходники сайта для проверки на отдельном тестовом origin. Исторические документы README-v14.6.txt, HANDOFF-v14.6.md, MIGRATION-v14.6.txt и SHA256SUMS-v14.6.txt относятся к **исходной версии** v14.6; последний не является перечнем хэшей нового кандидата.

### Что изменено
- `storage-guard.js` — общий слой защищённой записи, проверки чтением и предупреждения о конфликте другой вкладки.
- `app.js` — сохраняет намеренно пустой список ссылок, откатывает неподтверждённые отметки и ссылки; операции с архивом не закрывают форму при отказе записи.
- `planner.js` — проверяет запись задач, режима дня, заморозки, чата и регулярных занятий; не подтверждает неудачные изменения.
- `english.js` — проверяет сохранение сессий, словаря и ответов до отображения успеха.
- `index.html` и `sw.js` — подключение нового скрипта и раздельная версия кеша кандидата `14.7-p1`.

### Ограничения
Изменение из старой вкладки, где открыт **неисправленный** код v14.6, не может быть запрещено новым приложением: перед испытаниями закрыть предыдущие экземпляры или использовать отдельный тестовый профиль/домен. Проверка на настоящем localStorage, Service Worker и установленном PWA ещё нужна. Не очищать пользовательское хранилище ради установки.

Полный отчёт, контрольные суммы и CDP-сценарии находятся в отдельном пакете доказательств P1. При обновлении пользователю сначала следует сохранить полную резервную копию своих данных через интерфейс установленной v14.6.
