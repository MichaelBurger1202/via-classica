Via Classica v13.5.4

Fixes:
- The planner's main "Сегодня" date is rendered dynamically from the device's local calendar date instead of the old static 14 September text.
- The schedule importer now accepts the current Via Classica weekly-plan JSON (schema=via-classica-schedule-v1 with period/fixed_commitments/self_study/rotation) and expands it into dated tasks.
- Existing dated task exports remain supported.

Previous v13.5.1–v13.5.3 fixes are retained.
