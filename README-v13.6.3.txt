Via Classica v13.6.3

Обновление английской AI-тренировки по результатам реального теста.

Исправлено:
1. Повторное нажатие «Проверить ответ» после отправки больше не создаёт новое задание и не засчитывает ответ повторно.
2. В одной сессии задания не повторяются.
3. Блок «Ещё 5» не повторяет задания из основной десятки и блокирует задания из последних 15 выполненных AI-заданий.
4. Пройденные задания фиксируются в localStorage сразу после ответа; досрочный выход сохраняет checkpoint текущей сессии и позволяет продолжить позже.
5. Если закрыть тренировку после нескольких выполненных заданий, они не выдаются заново при продолжении.
6. Банк расширен до 31 уникального задания с разнообразием навыков и тем.
7. В банк добавлены материалы/ориентиры из всех шести рабочих источников: ФИПИ, IELTS.org, IELTS UP, Cambridge English, British Council LearnEnglish, Oxford Learner’s Dictionaries.
8. Для каждого задания сохраняется источник и ссылка на него.

Важно: реальные аудиозаписи Listening пока не подменяются искусственным «аудио» — текущий мобильный режим использует текстовые задания. Полноценный Listening/Speaking Lab остаётся отдельным следующим модулем.
