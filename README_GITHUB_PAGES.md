# Via Classica 2026–2029

Мобильный персональный планер подготовки к поступлению.

## Что умеет эта версия

- Главная: ежедневные задачи + план текущего месяца.
- Ежедневные задачи можно добавлять с типом: переносимая / фоновая / жёсткая.
- Можно задать длительность задачи.
- У каждого дня есть режим нагрузки: обычный, лёгкий, тяжёлый, каникулы, фестиваль/поездка.
- День можно заморозить: он не создаёт «долга».
- Невыполненные переносимые и фоновые задачи перераспределяются автоматически в ближайшие дни с доступной нагрузкой.
- Жёсткие дедлайны не двигаются автоматически.
- Есть ручная команда «Перестроить план».
- Можно отметить задачу выполненной, частично выполненной (25/50/75%), перенести или удалить.
- План детализирован до 31 декабря 2026; после этого предусмотрен квартальный пересмотр.
- Олимпиадный календарь учитывает ВСОШ: русский 16.09.2026, литература 01.10.2026, а также «Высшую пробу» по филологии 26 и 28.09.2026.

## Публикация через GitHub Pages

1. Создай публичный репозиторий, например `via-classica`.
2. Распакуй ZIP.
3. Загрузи **все файлы из папки** в корень репозитория: `index.html`, `styles.css`, `app.js`, `planner.js`, `README.txt`, `README_GITHUB_PAGES.md`.
4. Нажми **Commit changes**.
5. Открой **Settings → Pages**.
6. В **Build and deployment** выбери **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем **Save**.
7. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/via-classica/`.
8. На iPhone открой адрес в Safari → «Поделиться» → «На экран Домой».

Данные чек-листов и настроек хранятся локально в браузере устройства.
