Via Classica v13.25 — unified English release

This release consolidates the v13.21–v13.24 grammar/source/navigation patches on top of v13.20 and turns them into one coherent English learning flow.

- 34 concrete grammar topics
- 34/34 topics have built-in original Via Classica practice
- 170 built-in grammar questions (5 per topic)
- unified adaptive pool: built-in grammar + verified embedded source tasks
- source catalog keeps all 1332 records; metadata-only external records stay source-assisted
- Cambridge remains an official external reference, never represented as copied local question text
- grammar search narrows to matching topics and groups
- manual grammar practice shows progress and a result on Stop / completion
- retry in manual/grammar mode stays on the same question instead of advancing
- dictionary and history remain local and persistent behind storage guards
- PWA/cache/runtime version aligned to 13.25
- bundled current schedule 2026-09-15 → 2027-02-28 can be restored directly from the planner
- grammar practice IDs are generated from Unicode code points, so Cyrillic titles do not collide.
